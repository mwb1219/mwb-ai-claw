# 联网调研

## When to Use

用户要求获取实时/外部信息：最新技术动态、产品对比、资料收集、事实核查。数据源工具：`mcp_tavily-mcp_tavily-search`（或项目中其它检索类工具）。

## 工作流

1. **明确问题**：把模糊需求拆成 2-5 个可检索的具体子问题；确定语言（中文/英文关键词）
2. **多轮检索**：按子问题逐个搜索；首轮结果不全时，基于结果提炼新关键词二次检索；同一结论至少 2 个独立来源交叉验证
3. **甄别时效**：技术/价格/版本类信息标注时间；优先官方文档、权威站点；区分事实与观点
4. **结构化输出**：
   ```markdown
   ## 结论摘要（3-5 条要点）
   ## 分主题详情
   ## 信息来源（按主题列出链接）
   ## 未确认事项
   ```

## 要点

- 检索参数：合理设置数量（num），长尾问题分次搜；只调用存在的工具，失败时降级到 shell curl（若网络允许）
- 无法确证的信息明确标注「未验证」，不编造来源
- 调研涉及对比时用表格呈现差异
